# Учебные проекты по анализу данных

Учебные работы, выполненные самостоятельно во время обучения на направлении «Программная инженерия» в НГТУ. В проектах использованы Python и R для анализа данных, регрессии, кластеризации и классификации.

## Проекты

### Python

- [Лабораторная работа 1](notebooks/lab01_diamonds_exploratory_regression.ipynb) — исследовательский анализ данных о бриллиантах, подготовка данных и построение моделей регрессии.
- [Лабораторная работа 2](notebooks/lab02_diamonds_mlp_regression.ipynb) — построение и оценка нейросетевой модели регрессии с использованием TensorFlow.

### R

- [Лабораторная работа 1](reports/lab01_r_exploratory_analysis.docx) — первичный разведочный анализ данных, визуализация и статистические проверки. [Скрипт](scripts/lab01_eda.R)
- [Лабораторная работа 2](reports/lab02_r_clustering_classification.docx) — кластеризация и классификация данных. [Скрипт](scripts/lab02_clustering_classification.R)
- [Лабораторная работа 3](reports/lab03_r_classification.docx) — сравнение методов классификации. Для работы используются данные `var_7_lab2.csv` и промежуточный файл `lab2.RData`, созданный на предыдущем этапе. [Скрипт](scripts/lab03_classification.R)
- [Расчётно-графическое задание](reports/rgr_data_quality_ml.docx) — обработка данных и классификация на наборе о раковых опухолях. [Скрипт](scripts/rgr_data_quality_ml.R)

## Структура

- `notebooks/` — Python-ноутбуки;
- `scripts/` — R-скрипты;
- `reports/` — отчёты к лабораторным работам;
- `data/` — исходные CSV-данные.

## Данные и запуск

Файлы данных для R-работ находятся в `data/`. Для второй Python-лабораторной нужен файл `diamonds_nan_24_PREPARED.csv`; он создаётся при выполнении первой лабораторной после обработки `diamonds_nan_24.csv`.

Для Python установите зависимости из корня проекта:

```bash
pip install -r requirements.txt
```

Затем откройте нужный ноутбук в Jupyter. Для R установите пакеты, указанные в начале соответствующего скрипта. Скрипты используют относительные пути к файлам в `data/`.

Все проекты являются учебными.
